# Tower Of Endurance

Tower Of Endurance is a spin on the tower defence genre. In this game, players control a single tower that can be upgraded. Upgrades include increased damage, faster firing, and abilities such as applying poison damage over time or using artillery to target groups of enemies.

## Requiremetns
- Unity: 6000.0.27f1
- Unity Packages: 
    - Odin Inspector and Serializer 3.3.1.13
